# ClaudeUsageBar

Claude のプラン使用量（5時間枠・7日枠）を常時表示する、Windows 用の常駐アプリです。時刻は日本時間です。

> **非公式の個人用ツールです。Anthropic とは関係ありません。利用は自己責任でお願いします。** 詳しくは「免責・注意事項」を読んでください。

## 必要なもの

- Windows 10/11（x64）
- .NET 8 デスクトップランタイム（ビルドには .NET 8 SDK）
- Claude Code にサブスクリプションでログイン済みであること

## ビルド

```powershell
dotnet publish src -c Release -o publish
```

`publish\ClaudeUsageBar.exe` ができます。起動中は上書きできないので、先に終了してください。

## 起動と操作

`publish\ClaudeUsageBar.exe` を実行します。インストールは不要です。

- 横一列の表示で、初期位置はタスクバーの通知領域の左隣です
- ドラッグで移動できます。位置は保存されます。タスクバー上で放すと上下中央にそろいます
- 「タスクバーに配置」で初期位置に戻ります（横向きのタスクバー、メイン画面）
- 「色」で配色を6種類から選べます。50％・80％の警告色は共通です
- 50％以上は黄色、80％以上は赤です（表示する整数の％で判定）
- 5分ごとに更新します
- トレイアイコンかウィジェットの右クリックで「表示/非表示」「タスクバーに配置」「色」「今すぐ更新」「Windows起動時に開始」「終了」を選べます
- 「今すぐ更新」は前回の取得から30秒以内と、回数制限の待機中は動きません
- exe を移動したら「Windows起動時に開始」を選び直してください

## 「更新失敗」の意味

最後に取れた値と、その取得時刻を残して表示します。理由はウィジェットにマウスを重ねると出ます。

| 表示 | 対処 |
|---|---|
| トークン期限切れ | Claude Code を使うと更新される |
| 認証情報なし | Claude Code にログインする |
| 回数制限中 | 待つ（自動で再試行） |
| 通信エラー / HTTP ○○ | 通信状態を確認する |
| 応答形式エラー | 非公式エンドポイントの仕様が変わった可能性がある |

## 仕組みと注意

- `~/.claude/.credentials.json` を読み取り専用で開き、`https://api.anthropic.com/api/oauth/usage` にだけトークンを送ります。モデルは呼びません
- トークンの更新・保存・ログ出力はしません。リダイレクトも追いません
- 非公式のエンドポイントなので、予告なく動かなくなることがあります
- 保存するのは位置・表示状態・配色・最後の使用量だけです（`%APPDATA%\ClaudeUsageBar\state.json`）
- アンインストール：「Windows起動時に開始」をオフにして終了し、exe と `%APPDATA%\ClaudeUsageBar` を削除します

## 別の環境で使う

プログラムを転送できない環境では、プロンプトから作り直せます。

1. 別の PC で空のフォルダーを作り、Claude Code を起動する
2. [PROMPT.md](PROMPT.md) の枠内をすべてコピーして貼り付ける
3. 環境の確認から実装・動作確認まで進むので、結果の報告を確認する

仕様から作り直すため、細かい見た目やコードは同じになりません。別環境での作成は未検証です。
